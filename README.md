# 🌱 Smart Agriculture Advisor

## Overview

Smart Agriculture Advisor is an AI-driven agricultural decision support system developed to assist farmers with crop planning, disease identification, market analysis, weather monitoring, and agricultural insights.

The system integrates machine learning models, real-time APIs, and intelligent recommendation techniques into a single platform.

---

## Features

### 🌾 Crop Recommendation
- Predicts suitable crops
- Uses:
  - Nitrogen
  - Phosphorus
  - Potassium
  - Temperature
  - Humidity
  - pH
  - Rainfall

### 🧠 Explainable AI
- Explains why recommendations are generated

### 🍃 Disease Detection
- Detects crop diseases from images

### 🌦 Weather Forecast
- Real-time weather API integration
- Multiple state support

### 📈 Yield Prediction
- Predicts crop production

### 💹 Market Analysis
- Displays crop market information

### 📍 State Insights
- Supports all Indian states and UTs

### 🎤 Voice Assistant
- Speech-to-text interaction

### 🤖 AI Assistant
- Smart agricultural guidance

### 💰 Profit Recommendation
- Cost and expected profit analysis

### 🌐 Multi-language Support
- Supports Indian languages
